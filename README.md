## Approach

I built the agency website with a focus on clean structure and responsiveness. The layout is organized into clear sections (Hero, Services, Portfolio, About) to reflect a typical agency marketing site.

Components were designed to be reusable and easy to maintain, and the styling prioritizes readability and consistent spacing across devices. The Contact page integrates with the backend API and provides user feedback for both successful and failed submissions.

## Tech Stack

- **Framework**: React 18 with TypeScript
- **Build Tool**: Vite
- **Styling**: TailwindCSS
- **UI Components**: shadcn/ui
- **Icons**: Lucide React
- **Package Manager**: pnpm

## Setup Instructions

1. Install dependencies:
   ```bash
   pnpm install
   ```

2. Start development server:
   ```bash
   pnpm run dev
   ```

3. Open your browser and navigate to `http://localhost:5173`
